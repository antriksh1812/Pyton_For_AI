# Python for AI Project

This project can be set up easily by following the steps below.

## 1. Install Anaconda

Install Anaconda or Miniconda on your machine before creating the environment.

## 2. Create a local virtual environment

Run the following command from the project root:

```bash
conda create -p ./venv python=3.11 -y
```

## 3. Activate the environment

```bash
conda activate ./venv
```

## 4. Install dependencies

```bash
pip install -r requirements.txt
```

If no `requirements.txt` exists yet, install the required packages manually as needed for the project.

## 5. Start working

You can now run Python scripts, Jupyter notebooks, or project-specific commands inside the activated environment.
